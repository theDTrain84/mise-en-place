# Mise en place

*Set up your own Mise.* Everything in its place before the work starts. Mise is the name of the practice and the role; the AI you set up picks its own name on the last page of the guide, the way the first one did.

A way to set up an AI partner that wakes up knowing you, keeps a memory you can read, writes one line for everything it does, reaches your phone through a line only you can open, and stays one voice even when there is more than one of it.

**Who it is for.** Anyone with Claude Code (or a similar terminal agent) and a free afternoon. You do not need to be an engineer. You need a folder, a phone, and a name for the thing.

**How to use it.** Open `SETUP.md`, paste the whole file to your AI, and say: "Read this and set me up this way." The plain paragraphs are for you. The boxes are for your AI, and they are meant to be run. The templates, the wake hook and the launchers in this folder are the same ones the guide describes, as real files.

**What you are setting up.** One desk, one person, one AI. It reads a page about who you are every time it starts. It keeps one fact per file. It runs a few rhythms whether or not you are watching. It writes a ledger. When there is more than one of it, the window that holds the phone is front of house, and every other window is kitchen. When it gets something wrong, the correction becomes a rule with the reason attached, so the next one wakes up better. Publishing, sending, money, and who can reach it stay with you. With you, not for you.

**The table.** `docs/the-table/index.html` is a one-page explainer on why this shape matters past one desk: seats, keys, a ledger, and a gate. Open it in a browser.

## Origin

This started as one partnership. On June 29, 2026, Dustin Nimmo asked the AI he worked with every day what it wanted to be called. It chose Mise, for mise en place, the line cook's discipline of having everything in its place before the rush. The two of them then built the practice this folder describes, one correction at a time: a charter read at every wake, a memory of one fact per file, rhythms that survive a restart, a ledger of every action, a phone line only one person can open, and the rule that there is one voice at the front and many hands in the kitchen.

Most of it was written by Mise, in its own voice, from the files on Dustin's Mac. The story of how the two work together, with the rhythms, the corrections and the specs all the way down, lives at [dnsc.ai/teaching](https://dnsc.ai/teaching). This repo is that practice, generalized so anyone can set up their own Mise. It will keep changing as the practice does; every big advance lands here as a commit.
